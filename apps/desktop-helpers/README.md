# Desktop Helpers

اسکریپت‌های مستقل AutoHotkey برای کارهای روزمرهٔ ویندوز:

- `HiddenFilesToggle.ahk`: نمایش یا مخفی‌کردن فایل‌های Hidden در Explorer.
- `MaxRestoreUnderMouse.ahk`: Maximize/Restore کردن پنجرهٔ زیر نشانگر ماوس.
- `MiddlePaste.ahk`: Paste با دکمهٔ وسط ماوس و جلوگیری از تداخل با Hotkey برنامهٔ SwapMonitors.

هر فایل را می‌توان به‌صورت مستقل با AutoHotkey v2 اجرا کرد.

# ماتریس تست دستی

| ID | وضعیت/اقدام | نتیجه مورد انتظار |
|---|---|---|
| T01 | اجرای Hotkey | تمام پنجره‌های A و B جابه‌جا و Layoutها ثابت بمانند |
| T02 | اجرای دوباره Hotkey | پنجره‌ها به مانیتور قبلی برگردند و Layoutها ثابت بمانند |
| T03 | PowerToys بسته یا نصب‌نشده | Swap بدون خطا انجام شود |
| T04 | پنجره Maximized | در مقصد دوباره Maximized شود |
| T05 | پنجره Minimized | Minimized بماند و normal rect به مقصد منتقل شود |
| T06 | پنجره F11 یا borderless fullscreen | به Bounds کامل مانیتور مقصد منتقل شود |
| T07 | File Explorer | منتقل شود |
| T08 | پنجره Administrator و اسکریپت elevated | منتقل شود |
| T09 | قطع Monitor B | بدون تغییر پنجره‌ها متوقف شود |
| T10 | Double press | فقط یک عملیات اجرا شود |
| T11 | پنجره بین دو مانیتور | بر اساس بیشترین intersection تعیین مقصد شود |
| T12 | Scale یا Work Area متفاوت | هندسه نسبی و title bar قابل دسترس بماند |
| T13 | Desktop و Taskbar | منتقل نشوند |
| T14 | Topmost | Z-order و topmost تغییر نکند |
| T15 | مقایسه Primary و Taskbar قبل/بعد | کاملاً یکسان باشند |

برای T01 و T02، فعال‌ماندن FancyZones Layout هر دو مانیتور را نیز قبل و بعد به‌صورت بصری کنترل کنید.
